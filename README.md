ParkSmart AI – Smart Parking Availability & Booking System

Developed a full-stack AI-based smart parking management system with real-time slot monitoring, advance booking, QR-based ticketing, and parking navigation assistance using React, Firebase, Firestore, and Python.

Key Features Implemented real-time parking slot availability monitoring using Firebase Firestore listeners. Built advance slot booking system with conflict prevention using Firestore transactions. Developed QR code-based parking ticket generation for booking verification. Integrated Firebase Authentication for secure user login and registration. Designed live parking occupancy dashboard with automatic real-time updates. Created navigation guidance module for directing users to booked parking slots. Developed Python-based IoT simulator to mimic sensor-driven parking occupancy updates. Implemented responsive frontend UI using React Hooks and React Router. Technologies Used React.js Firebase Authentication Cloud Firestore Python Firebase Hosting Framer Motion QR Code Generation JavaScript HTML5 CSS3 Responsibilities Designed frontend architecture and booking workflow. Integrated Firebase backend services and authentication. Developed Firestore database schema and security rules. Implemented real-time synchronization using Firestore listeners. Built Python simulator for parking occupancy simulation. Deployed application using Firebase Hosting. Outcome Reduced parking slot booking conflicts using transaction-based validation. Enabled real-time parking monitoring with low-latency updates. Improved user experience with digital ticketing and navigation support.
